# 在文章中嵌入网易云音乐播放器

文章正文支持使用短代码嵌入网易云音乐的单曲、专辑或歌单播放器。

## 写法

将短代码单独放在一段中，不要与其他文字写在同一段：

```text
[music type="song" id="歌曲ID"]
[music type="album" id="专辑ID"]
[music type="playlist" id="歌单ID"]
```

例如：

```text
[music type="album" id="3196324"]
```

`type` 只能使用以下三个值：

| `type` | 内容 | 播放器行为 |
|:--|:--|:--|
| `song` | 单曲 | 只显示单曲播放器，不显示歌单按钮 |
| `album` | 专辑 | 显示专辑曲目，可展开曲目列表 |
| `playlist` | 歌单 | 显示歌单曲目，可展开曲目列表；列表过长时可以滚动 |

属性顺序可以交换，但建议保持示例中的顺序。ID 必须是纯数字，推荐使用英文半角双引号。

## 如何找到 ID

打开网易云音乐网页版并查看地址栏：

```text
https://music.163.com/#/song?id=1974443814
                               └─ 歌曲 ID

https://music.163.com/#/album?id=3196324
                                └─ 专辑 ID

https://music.163.com/#/playlist?id=歌单ID
                                   └─ 歌单 ID
```

只复制 `id=` 后面的数字，不要粘贴完整网址。

## 歌词行为

- 有时间轴的歌词会跟随播放进度滚动并高亮当前行。
- 用户手动滚动歌词后会暂时停止自动居中；停止操作一段时间后恢复跟随。
- 没有时间轴的歌词只静态显示，不会伪造同步效果。
- 歌曲没有歌词时显示「这首歌暂无歌词」，同时不显示无意义的歌词展开按钮。

## 已知限制

- 目前短代码只在正常文章详情页中解析，关于页面暂不支持。
- 播放地址、封面和歌词来自网易云音乐及 Meting 服务，服务不可用时播放器会显示加载失败。
- VIP、付费、地区限制或版权受限的歌曲可能只能播放约 30 秒试听片段。这是上游返回的音频限制，播放器不会也不能将其变为完整版。
- 已下架、无播放权限或没有可用音频地址的歌曲可能无法播放。

## 排查

短代码被显示成普通文字时，依次检查：

1. 是否位于正常文章详情页，而不是关于页面。
2. 是否单独占据一个段落。
3. `type` 是否为 `song`、`album` 或 `playlist`。
4. `id` 是否只包含数字。
5. 引号是否为英文半角引号，而不是中文弯引号。

播放器已经出现但无法加载时，可在浏览器网络面板检查：

```text
/api/lab/music?type=类型&id=数字ID
```

接口返回 `200` 但只能播放 30 秒，通常属于网易云版权或 VIP 试听限制。
