# Fonts Directory

This directory contains self-hosted web fonts.

## SN Pro (UI Font)
- SNPro-Regular.woff2
- SNPro-Medium.woff2
- SNPro-SemiBold.woff2
- SNPro-Bold.woff2

## Newsreader (Editorial Serif)
- Newsreader-Regular.woff2
- Newsreader-Medium.woff2
- Newsreader-SemiBold.woff2
- Newsreader-Bold.woff2
- Newsreader-Italic.woff2

## MiSans (Chinese Sans)
- `MiSans-Regular-v2025.woff2` (weights 400–500)
- `MiSans-Semibold-v2025.woff2` (weights 600–900)

These are unmodified WOFF2 files from Xiaomi's official MiSans package, font
version 4.589. The versioned filenames allow immutable browser caching. MiSans
is used under the [MiSans Font Intellectual Property License Agreement](https://hyperos.mi.com/font/zh/download/).

## Download Sources
- **SN Pro**: Available from various font foundries
- **Newsreader**: Google Fonts (https://fonts.google.com/specimen/Newsreader)
- **MiSans**: [Xiaomi official font](https://hyperos.mi.com/font/zh)

## Conversion
Use tools like `woff2` or online converters to generate .woff2 files from .ttf/.otf sources.
